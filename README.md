# 🏪 Fiara POS — Sistema Web para Bodegas y Minimarkets en Perú 🇵🇪

> **El punto de venta web diseñado para bodegas, minimarkets y puestos de mercado peruanos.**  
> Cobra rápido con Yape, Plin o Efectivo, calcula el vuelto al instante, lleva tu libreta de fiados digital y cuadra tu caja diaria **100% sin internet**.

## ✨ Características Principales

- ⚡ **Cobro y Vuelto al Instante:** Registra ventas en segundos con cálculo automático de vuelto para billetes de S/ 20, S/ 50 o montos manuales.
- 📱 **Soporte Yape y Plin:** Botones de un toque para registrar pagos digitales populares en Perú.
- 📔 **Libreta de Fiados Digital:** Anota qué vecino llevó fiado, cuánto pagó a cuenta y el saldo pendiente sin peligro de hojas rotas o perdidas.
- 📴 **100% Offline (Sin Internet):** Funciona y guarda todas tus cuentas en la memoria local de tu celular aunque estés en un mercado sin cobertura o sin megas.
- 🔒 **Cierre de Caja y Gastos:** Arqueo diario automático sumando ventas y descontando pagos a proveedores.
- 🌗 **Modo Claro y Modo Oscuro:** Interfaz optimizada para cualquier condición de luz.
- 📲 **Cero Descargas:** Aplicación web ultraligera que se agrega directamente a la pantalla de inicio del celular.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico** con microdatos estructurados Schema.org (JSON-LD) para SEO en Google.
- **Tailwind CSS** (CDN) con diseño responsivo móvil-primero (*mobile-first*).
- **Vanilla JavaScript** para la calculadora interactiva, simulación de cobros y cambio de tema.
- **SVG Vectorial** para iconografía y logotipo de alta fidelidad sin peso adicional.

## 🌐 Cómo Publicar en GitHub Pages (Paso a Paso)

1. **Crea el repositorio en GitHub:**
   - Nombre recomendado: `fiara-pos`
   - Déjalo en **Público**.
2. **Sube los archivos:**
   - Sube `index.html` y `README.md`.
3. **Activa GitHub Pages:**
   - Ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú izquierdo, haz clic en **Pages**.
   - En **Build and deployment > Source**, selecciona `Deploy from a branch`.
   - En **Branch**, elige `main` (o `master`) y la carpeta `/(root)`.
   - Haz clic en **Save** (Guardar).
4. **¡Listo!** En unos 60 segundos, GitHub te dará tu link público (ejemplo: `https://tu-usuario.github.io/fiara-pos/`).
